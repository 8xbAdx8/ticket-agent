# 确认与异常矩阵

| 场景 | 状态 | 证据/边界 |
|---|---|---|
| 锁座、下单、支付逐次确认 | 两模型真实执行 | `*-full-summary.json`；隔离数据库 |
| 拒绝锁座 | DeepSeek 真实验证 | locks 0 → 0；Qwen 前置工具失败，未完成 |
| 重复拒绝 | DeepSeek 真实拒绝 | 仅验证无待确认的重复拒绝，不等同支付幂等全覆盖 |
| 更改车次/日期或切换会话 | 未做本轮真实完整验证 | 不能宣称通过 |
| 刷新、确认过期 | TTL / 参数绑定离线验证；浏览器刷新待验证 | 10分钟内存 TTL；不代表持久化确认 |
| 模糊确认、确认参数不符 | 离线测试 | 严格布尔与 proposal 绑定 |
| 超时、429、工具参数异常、锁过期 | 现有离线故障测试部分覆盖 | 本轮未制造真实超时或429 |
| SQLite 写失败、执行成功后模型失败 | 尚未完成本轮逐项证据审计 | 需 B 独立测试 |

每条记录不可将 stop 等同业务成功；非确定结果不标 PASS。
