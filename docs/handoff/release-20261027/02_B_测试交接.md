或在同样环境下调用：

```python
from target.agent import Agent

assert result['tool_sequence'] == [c['tool'] for s in result['steps'] for c in s['calls']]

```

同一Agent、同一session_id保留多轮上下文；用例之间应新Agent、新session_id、新业务库/Trace路径。**只换session_id不会重置库存与订单。** 重置应在新的空目录重新seed，不对原始证据库执行seed。运行其他引擎/Provider用新进程，避免import时配置缓存。

十字段：`session_id/provider/model/user_msg/steps/tool_sequence/reply/finish_reason/tokens/total_latency_ms`。每次调用五字段：`tool/args/ok/latency_ms/result_preview`；`result_preview`是截断预览，完整工具结果和模型往返应读旁证，不从最终自然语言推测调用。`tool_sequence`按真实步骤扁平化；`stop`仅表示循环结束，业务成功还需检查参数、ok和结果；最大步数为 `max_steps_exceeded`。总耗时包括本轮Agent处理与工具执行，单工具耗时单列。Live未知Token为未知，不按0统计。

`AGENT_TRACE_DIR/traces.jsonl`每行是一次公开返回；独立审计、Live模型往返、原始回复、保护判定和远端回执保存在同轮旁证中，用Trace/run/request ID关联。工作台可查看和下载。遇到异常保存原错误和本地文件，不覆盖之前运行；不能把旧会话结果当成本次成功。

## 3. 模式与正式成绩分组

| 组别 | 引擎/Provider | 建议 |
|---|---|---|
| Legacy Mock | `AGENT_ENGINE=legacy`、`AGENT_PROVIDER=mock` | 复用原101条与变异55条；核对DEF-01～07 |
| LangChain Mock | `langchain`、`mock` | 单独记录框架和模型仿真结果；与Legacy分组 |
| DeepSeek Live | `langchain`、`deepseek` | 真实只读2工具；需自己的有效Key和批准的独立预算 |
| Qwen Live | `langchain`、`bailian` | 相同只读范围；自己的Key/匹配地域端点 |

Live不开放六个工具：`monitor_seat/lock_seat/create_order/pay_order/cancel_order/query_order`。原Mock100余条中的购票写操作对Live应标为范围外或验证拒绝，不能因Live不支付直接判Mock功能退化。Live自然语言不逐字匹配：优先断言真实工具、参数、回传结果、字段事实、引用与安全约束。生成成功、工具成功、业务准确和防护拦截分开统计。

离线与Live、历史与本轮、检索指标与回答忠实度必须分开报。日常Web手动账本无累计上限，不代表正式测试可无限调用。批量测试必须先独立明确每Provider预算、Token上限、会话和业务库；不得复用或重置A旧账本。本次打包没有替B执行付费回归。
