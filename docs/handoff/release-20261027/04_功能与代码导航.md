## 八工具

完整JSON Schema（类型、枚举、可选字段）以 `target/tools.py` 的 `TOOLS` 为准，返回值看该工具实际函数和模拟后端，不将下表当成新增契约。

| 名称 | 主要参数 | 实际作用/结果 |
|---|---|---|
| query_tickets | from_city,to_city,date；可选kind,seat_type等 | 返回虚构班次、时刻、价格、余票或空结果 |
| monitor_seat | train_no,date,seat_type | 订阅模拟候补监控，不代表已经出票 |
| lock_seat | train_no,date,seat_type,passengers | 检查库存与条件，生成有有效期的lock_id |
| create_order | lock_id,passenger_ids,contact | 依据有效锁座创建订单，同lock幂等 |
| pay_order | order_id | 模拟支付状态变更；重复支付不重复扣款 |
| cancel_order | order_id | 模拟取消/退票及政策费用，不接真实退款 |
| query_order | order_id或phone | 查询本人模拟订单，身份约束仍生效 |
| search_policy | question | 返回检索政策与可检查doc_id；不能由引用存在推断全文支持 |

Live仅query_tickets/search_policy。Mock可演示八工具，不应在Live解锁写工具来凑完整流程。

## RAG指标和未知项

政策15条，固定30题与新增48题分开；新增48题分开发/保留各24。完整48题Keyword Recall@1=.84375、Recall@3=1、MRR=.9375；Vector/Hybrid各.96875/1/1，无答案误召回0/32。这里Recall按相关文档集合计，MRR按首个相关文档排名计，两者不能互换。

这些是冻结测试集与真实向量缓存的检索成绩，不是所有用户问题的模型回答准确率。DeepSeek和Qwen历史P11全文忠实度均INDETERMINATE，必须逐句对照并由B裁定。未实现完整Live六写/订单工具；未保证任意新问题均有缓存、任意第三方端点兼容或全部语义自动可判。
