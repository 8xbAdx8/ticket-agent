## 现在怎样用

1. 在自己原来的启动终端按 `Ctrl+C`，再双击项目根目录的 `启动_在线模式.cmd`。启动器不发送模型请求。
2. 打开终端打印的 localhost 地址。左侧“新会话模型”可选 `DeepSeek Live` 或 `Qwen3.8-Flash Live`，切换后创建独立会话、数据库和 Trace。
3. 输入“查明天上海到杭州的高铁二等座”，勾选真实请求费用确认，点击发送。
4. 发送后真实模型选择工具，LangChain 执行现有 Python 工具，再把实际结果返回模型。一次对话可能产生多次 API 请求。
5. Live 只允许 `query_tickets`、`search_policy`。模拟锁座、下单、支付等仍在离线 Mock 中演示。六个其他 Live 工具由代码白名单禁止。

用户新会话标记 `interactive=True`。历史验收会话保留供回放，不能借用新授权继续消费旧账本。启动器也不再因为继承的旧 CLI 额度已耗尽而阻止日常网页启动。

日常账本：

- DeepSeek：`artifacts/runtime/manual-live/deepseek/requests.db`。
- Qwen：`artifacts/runtime/manual-live/bailian/requests.db`。
- `max_requests=0` 表示不限制累计生成请求数，仍逐次记账，不等于免费。
- 单轮最多 3 次模型调用、工具次数/Token 安全预算、超时和零自动重试仍保留，以防失控循环。
- 日常默认政策检索使用本地 Keyword；`RAG_ALLOW_NETWORK=0`，不自动消费历史 Embedding 账本。向量实验仍应使用既有独立验收入口及授权。

## Key 配置

已有 Key 无需重配。DeepSeek 读取 `DEEPSEEK_API_KEY`；千问读取 `DASHSCOPE_API_KEY`，并需要与 Key 地域/套餐匹配的 `DASHSCOPE_BASE_URL`。网页选项显式使用 `qwen3.8-flash`，不因其他环境中残留 `qwen-plus` 而静默回退。

不把 Key 粘贴到网页消息、报告或聊天。若需要重新配置，在 PowerShell 中隐藏输入并保存到当前 Windows 用户环境：

```powershell
# 配置 DeepSeek；千问将两处变量名改为 DASHSCOPE_API_KEY。
$secureKey = Read-Host '输入 API Key（隐藏）' -AsSecureString
$credential = New-Object System.Net.NetworkCredential('', $secureKey)
[Environment]::SetEnvironmentVariable('DEEPSEEK_API_KEY', $credential.Password, 'User')
Remove-Variable credential, secureKey
```

随后重新启动在线入口。配置地址时可用普通环境变量，例如标准北京地域按量付费兼容地址为 `https://dashscope.aliyuncs.com/compatible-mode/v1`；其他地域/套餐必须使用匹配地址。启动脚本只补齐进程中缺少的用户级配置，不打印 Key。项目 `.env` 中显式空值可能覆盖用户变量，检查配置来源后再启动，不要随意删除已有本地配置。

## LangSmith 怎样用

本机 `LANGCHAIN_API_KEY` 已配置，项目本地 `artifacts/runtime/ui-preferences.json` 只保存开启/关闭布尔值，不保存密钥，并被 Git 忽略。

开启的是**脱敏白名单导出**，LangChain SDK 自动上传仍关闭。上传范围为本轮输入、固定只读系统提示、最终回复、只读工具参数及模拟结果、模型/Token/耗时/错误类别/本地 Trace ID；不上传完整会话、认证信息、原始思维链、订单或审计旁证全文。

1. 可在“测试工作台→集成中心”查看“已启用脱敏导出；当前远端待核验”，也可切换开关。
2. 完成一次 Live 调用后，在出行助手展开“LangSmith 可选远端追踪”。失败但已保存旁证的 Live 调用也可查看脱敏预览。
3. 检查预览内容，勾选上传同意，再点“导出本轮并验证远端”。这一步才发送 POST + GET，模型生成计费与远端上传分开统计。
4. 以该次回执的 `remote_verified=true` 为远端成功依据。开关打开不等于已经上传成功。当前修复过程未发送新的 LangSmith 请求；V3.4 合成上传历史证据仍保留。
