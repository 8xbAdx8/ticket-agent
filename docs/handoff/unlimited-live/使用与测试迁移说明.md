# 全部 Live 入口：使用与测试迁移说明

日期：2026-10-27。适用分支：`feat/ticket-agent-unlimited-live`。本地累计请求次数不设上限，**真实模型及 Embedding API 可能产生费用**，服务商认证、配额、限流及账单仍适用。

## 1. 更新后启动

在原启动窗口按 Ctrl+C，退出旧 Streamlit 进程，再双击项目根目录 `启动_在线模式.cmd`。仅刷新浏览器可能继续使用旧 Python 模块和旧客户端。启动器默认 DeepSeek；页面左侧可选 Qwen3.8-Flash Live，新建对应会话。

如果只有百炼 Key，可直接启动百炼页面，不需要填假的 DeepSeek Key：

```powershell
cd D:\codexproject\ticket-agent
.\.venv-v35\Scripts\python.exe scripts/live_providers.py --provider bailian --profile v35 --serve
```

启动和打开页面不调用模型；每次勾选费用确认、点击“发送”或“执行测试”才发起请求。一次 Agent 对话可能包含多次模型请求。出行助手与测试实验室使用同一策略，实验数据与普通会话隔离。

离线仍可双击 `启动_离线模式.cmd`，不需要 Key、不调用模型。Live 不会因失败偷偷回退 Mock。

## 2. Key 和地址

已有 Key 配置无需重置。支持进程环境变量、Git 忽略的项目本地配置和 Windows 用户环境变量；详细隐藏输入步骤沿用 [安装与 API Key 配置](../release-20261027/01_安装启动与API配置.md)。不要提交真实 `.env`，不要将 Key 粘贴到对话、截图或 Trace。

| 用途 | 必要配置 | 模型与地址 |
|---|---|---|
| DeepSeek | `DEEPSEEK_API_KEY` | `DEEPSEEK_MODEL` / `DEEPSEEK_BASE_URL`，默认 `deepseek-flash` / `https://api.deepseek.com` |
| Qwen | `DASHSCOPE_API_KEY` | `DASHSCOPE_MODEL=qwen3.8-flash`，`DASHSCOPE_BASE_URL` 必须匹配账号地域与套餐 |
| Embedding | `DASHSCOPE_API_KEY` | `RAG_EMBEDDING_MODEL=text-embedding-v4`，可用 `DASHSCOPE_EMBEDDING_BASE_URL` 指定兼容地址 |

只有北京标准按量付费兼容接口才使用 `https://dashscope.aliyuncs.com/compatible-mode/v1` 示例地址。配置存在不证明账号有权限、余额充足或本次连接成功。缺少 Key 会明确报错。

## 3. RAG 网络确认

出行助手或测试实验室选择 Keyword/Vector/Hybrid。Keyword 不产生 Embedding 请求；Vector/Hybrid 命中真实缓存时不发新请求；未命中缓存时，勾选该轮 Embedding 费用与网络确认才能请求新向量。

“测试工作台 → RAG 知识库”同样保留 Embedding 确认和执行按钮。默认关闭网络；仅勾选或刷新不会执行。原冻结 Chroma 仍禁止原地构建，查询在独立副本进行并核对原索引哈希。创建新的索引版本需要独立 `RAG_INDEX_DIR`，这是索引保护，不是必须创建预算批次。

## 4. 命令行

以下两条只有本地预检，不发请求：

```powershell
.\.venv-v35\Scripts\python.exe scripts/live_providers.py --provider deepseek
.\.venv-v35\Scripts\python.exe scripts/live_providers.py --provider bailian --profile v35
```

以下是**使用者未来主动执行的付费命令示例，本轮未执行**：

```powershell
# 真实查票 Agent
.\.venv-v35\Scripts\python.exe scripts/live_providers.py --provider deepseek --run --scenario tickets
# Qwen 政策咨询，允许为 Hybrid 查询新增 Embedding
.\.venv-v35\Scripts\python.exe scripts/live_providers.py --provider bailian --profile v35 --run --scenario policy --rag-mode hybrid --allow-embedding
# 只请求检索，允许新增查询向量，不调用生成模型
.\.venv-v35\Scripts\python.exe scripts/rag.py retrieve --mode hybrid --question '锁座后多久必须完成支付？' --run
```

不需要 `MAX_REQUESTS`、共享额度、账本重置或新的授权批次。默认自动生成独立证据目录；显式 `--out` 不覆盖已有证据，换一个输出目录只是证据保护要求。

`verify_v34_live.py`、`verify_v35_live.py`、`verify_v352_live.py` 等旧入口也已移除累计计数拦截。V3.5 的兼容入口改为当前 Qwen 场景；旧 `--resume-rag-only` 是新的一轮 Qwen 政策查询，不表示重新证明整套历史双模型验收。V3.5.2 双模型入口保留相同证据/索引校验与每轮有限步骤。`evaluate_v352_rag.py` 的旧 `--authorize-embedding-requests` 仅兼容解析、没有限额效力，当前显式 `--run` 才表示允许新增 Embedding。

## 5. 查看用量

默认位置：`artifacts/runtime/api-usage/<provider>/<namespace>/requests.jsonl`。Provider 分别是 `deepseek`、`bailian`、`embedding`。`TICKET_API_USAGE_DIR` 可调整日志存放位置；历史 ledger 路径只用于生成 namespace，不读取其额度或状态来决定能否发请求。

| 字段 | 含义 |
|---|---|
| `event` | `request_started` / `request_finished`；同 ID 关联一次请求尝试 |
| `request_id` | 本地请求 UUID，不是计费成功证明 |
| `origin` | `real_api`、`offline_stub` 或自定义传输未验证；禁止混算 |
| `trace_id` / `model_step` / `tool_call_id` | 关联本地 Agent/RAG 审计记录 |
| `status` / `category` | 实际 HTTP 状态和错误类别；超时保留结果未知 |
| `requested_model` / `actual_model` | 请求配置与服务商实际返回标识分别记录 |
| `prompt` / `completion` / `tokens` | 生成输入/输出或 Embedding 总 Token；缺失为 JSON `null`，页面显示“未知” |
| `latency_ms` / `server_request_id` | 实际耗时与服务端返回的 ID（若有） |
| `cost` | 没有可靠账单依据时为 `null`，不是免费或费用 0 |

工具参数、实际结果、保护层判定仍在本地 Trace / sidecar，通过上述 ID 关联；用量日志不复制完整对话或认证头。集成中心显示当前使用统计。旧 SQLite 请求账本不删除、不更新、不清空；其未知状态不影响新请求。

统计磁盘不可写或日志损坏时 API 仍可执行；有审计上下文时记录 `usage_recording_warning`，统计显示未知/部分不可用。不能把磁盘故障时的计数当作完整账单；请检查目录权限并保存 Trace。

## 7. 仍保留的边界

只开放 `query_tickets`、`search_policy`；锁座、创建订单、支付、取消、查询订单、监控余票等其余六工具继续禁止真实 Live。仍有单轮模型/工具步数、单轮 Token/载荷保护、请求超时、0 自动重试、显式网络许可、索引版本校验和全文忠实度检查。`finish_reason=stop` 只表示循环结束，不能当作业务成功。

不限制累计次数，不等于不限制单轮循环，也不等于 API 免费。LangSmith 仍是单独手动确认的脱敏导出，不因本次变更自动上传。本轮未新增真实在线验证；C 可展示离线演示或历史带版本的真实证据，不得称这次离线桩为 Live 成绩。
