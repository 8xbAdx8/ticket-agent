# Windows 一键启动修复说明

日期：2026-10-27。分支 `feat/ticket-agent-unlimited-live`。本次修复源码提交：`0278560`。

## 查到的问题

1. 在线 `.cmd` 通过 PowerShell 直接执行 `scripts/launch_app.py`。Python 将 `scripts/` 而非项目根目录放在模块搜索路径中；在线预检导入 `target.api_usage` 时实际报 `ModuleNotFoundError: No module named 'target'`。原单元测试在项目根目录导入模块，未覆盖此入口，因此此前没有发现。
2. 两个 PowerShell 启动器原来只选择第一个存在的虚拟环境；若它损坏或缺少依赖，不会尝试其他已存在的环境。
3. 两个 `.cmd` 在失败时调用 `pause` 后丢失原退出码，外部程序可能误以为启动成功。
4. 在线入口之前只接受 DeepSeek Key；仅配置百炼 Key 和地址时仍要求 DeepSeek。项目本地 `.env` 的配置也没有在启动器预检前加载。

离线入口在修复前于本机**成功通过预检并启动了本地 Streamlit**；没有复现它本机必然失败。上述虚拟环境选择和退出码问题同样适用于离线入口，已共同修复。

## 修改

- `scripts/launch_app.py`：为直接执行方式加入项目根目录；仅在线时读取已配置的受保护项目 `.env`；没有 DeepSeek Key 但有百炼 Key 时，选择 Qwen，缺少百炼地址时清楚报错。
- `scripts/Start-TicketAgent.ps1`：按顺序检查现有虚拟环境能否运行且依赖是否可用，自动跳过损坏环境。全部不可用时显示 Python 3.12 与 V3.5 依赖的安装命令，不自动安装。支持本地预检、无浏览器和隔离目录参数；离线测试开关禁止从 Windows 用户环境读取真实 Key。
- `启动_在线模式.cmd`、`启动_离线模式.cmd`：传递可选参数，保留 PowerShell 原始退出码；正常双击方式保持不变。
- `tests/test_launcher_entrypoints.py`：直接调用两个 Windows `.cmd` 和 PowerShell 入口，检查实际本地服务、环境回退、Key/地址缺失与脱敏。

## 如何使用

1. 如果旧窗口正在运行，先在那个窗口按 Ctrl+C，再双击 `启动_离线模式.cmd` 或 `启动_在线模式.cmd`。
2. 离线模式无需 Key。在线模式优先使用 DeepSeek；只有 `DASHSCOPE_API_KEY` 时，需同时配置与账号地域和套餐匹配的 `DASHSCOPE_BASE_URL`，启动器自动选择 Qwen。两种 Key 均配置时可在网页左侧切换模型。
3. 仅启动或刷新页面不会调用模型。实际发送前勾选费用确认；真实 API 按提供商规则计费。
4. 如果显示缺少依赖，在项目目录按启动器显示的命令创建 `.venv-v35` 并安装 `requirements-v35-lock.txt`。安装需要可用的 Python 和包下载网络；不是启动器自动执行的操作。

可选的本地预检：

```powershell
cd D:\codexproject\ticket-agent
.\启动_离线模式.cmd -CheckOnly
.\启动_在线模式.cmd -CheckOnly
```

预检只报告配置是否存在和当前提供方，不验证真实 Key、余额或模型服务。不要将完整 Key 放入命令历史、截图或聊天。

## 已执行的验证

- 两个 `.cmd` 的实际预检：离线、DeepSeek 假 Key、仅百炼假 Key 和地址均通过；没有设置 `PYTHONPATH`，也没有发送模型请求。
- 两个模式各自用独立临时 SQLite、Trace 和端口启动真实本地 Streamlit 服务，健康接口返回 HTTP 200；测试关闭自己创建的服务，未启动浏览器和未发送对话。
- 测试覆盖损坏的第一个 Python 环境、缺少 Key、百炼缺少地址、`.env` 读取和凭据不输出。故障退出码均为 2。
- 启动器专项：**14 项通过，另 5 项子测试通过，0 失败**。
- 完整当前环境回归：**665 项通过，另 101 项子测试通过，0 失败、0 跳过**。旧环境兼容和历史文件核验见本轮新增验证摘要。
- 首次启动器专项有 3 项失败：2 项暴露 `.cmd` 吞掉退出码，另 1 项是测试清理依赖 WMI 时权限不足。保留了失败现象，修复退出码并将测试改为仅停止核验为自身子进程的本地服务后，专项及全量回归通过。
- 真实 DeepSeek、Qwen、Embedding 和 LangSmith 请求：**0**。本轮根据可重复的本地测试定位并验证了启动问题，没有必要使用付费请求；先前 Live 证据仍属于历史版本。
