## 3. 使用统计与证据

新日志默认 `artifacts/runtime/api-usage/<provider>/<namespace>/requests.jsonl`，由 `TICKET_API_USAGE_DIR` 配置根目录。旧 ledger 的路径字符串仅作为命名空间散列标签，不读取它的额度、状态或 schema 决定执行许可，也不向原 SQLite 写入。

记录 Provider、请求/实际模型、UUID、HTTP 状态、服务端请求 ID、输入/输出或 Embedding Token、耗时、错误类别、Trace/工具调用关联 ID。完整工具参数和结果仍在 Trace/sidecar，通过 ID 关联。费用在没有可靠账单时为 `null`；统计日志的成功不等于模型、工具或业务成功。

`origin` 区分真实 HTTP、离线 MockTransport、自定义传输待验证。缓存命中不计作新 Embedding 请求。磁盘不可写/损坏时记录警告并将统计标为未知/部分不可用，不拒绝 API；因此日志可能不是完整账单，应以服务商账单核对。

收尾回归发现 UUID 中连续 11 位数字被手机号脱敏正则误改，造成偶发关联 ID 错误。已将手机号边界改为排除英文数字标识符，新增固定 UUID、真实手机号及凭据的同时断言；保持手机号/密钥脱敏，历史记录未重写。

## 4. 保留的执行保护

- 用户主动点击发送、执行按钮或显式 `--run` 才请求；页面刷新、模型选择、模块导入不调用模型。保留模型与 Embedding 费用确认。
- DeepSeek/Qwen Live 仍只开放 `query_tickets`、`search_policy`。真实 HTTP 传输额外核验两个只读工具，不能借用离线 `full_sandbox` 扩大真实模型工具清单。
- SDK 自动重试为 0；超时、401/403/402/429/5xx、工具失败仍留证，不静默退回 Mock。超时结果可能未知，不自动补发。
- 单轮模型调用默认 3 次、工具调用默认 4 次，配置仍受安全区间约束；特定双模型验证仍保留每轮 2 次。单轮 Token、最大输出、载荷、请求超时、Agent 步数仍生效。这些是防循环保护，不是跨轮累计请求配额。
- 密钥和认证头脱敏；不上传内部推理；LangSmith 继续独立显式确认，不因本次变更自动导出。
- 冻结 Chroma 的版本/哈希校验、只在工作副本查询、Trace 审计、回答与数据/全文忠实度规则均保留。`Agent.chat()` 十字段及工具调用契约未修改。
