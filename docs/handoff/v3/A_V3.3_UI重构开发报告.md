## 安全与兼容

1. `Agent().chat(session_id,message)`、十字段及工具 calls 五字段保留原样。
2. 新 UI 的数据库/Trace 位于 `artifacts/runtime/v33/user/<sid>/` 或 `lab/<sid>/`。旧库和历史证据不迁移、不重置；旧订单不会自动复制到新会话。
3. 每次实际模型/工具操作只在明确提交时执行；浏览、切页、筛选、换主题不请求模型。重复提交回执不再次执行。
4. Live 只读工具仍是 `query_tickets`、`search_policy`；原代码层白名单、写授权、预算、超时和零重试不修改。前端不把错误回复替换为成功文本。
5. API Key 不进 UI 配置字段、结果副本、Trace 或文档。集成中心只显示配置是否存在。JSON/CSV 经过脱敏，CSV 公式前缀按安全文本导出。
6. LangSmith 外传关闭。确认组件不是 LangGraph interrupt，也不绕过后端校验。
7. 没有阶段时间戳时显示“未提供”；不把模型总耗时减工具耗时冒充模型耗时；Mock Token 不适用，未知 Token 不填零。

## 已知限制与后续

- 新版 Live 没有联网回归；历史 V3.1 full_sandbox 曾实际执行查票/锁座/创建模拟订单，不代表八工具全部通过，更不代表当前默认开放写操作。
- 原 B 测试脚本退出码/N/A 风险、T04 盲区未在本轮更改，应由 B 维护正式层。
- B 压缩结果没有完整工具参数、临时库和本轮 audit 原件；查看时明确标缺失，不能补造关联 Trace。
- 同一 Streamlit 进程的 UI 渲染/调用串行；未验收多用户吞吐、多进程或公网部署。前端不是身份鉴权系统。
- 对话内存只在当前 Streamlit 会话中保留，切页可继续；浏览器完整刷新/重启后不保证恢复记忆，磁盘 Trace 仍保留。
- UI 对常见业务请求附加确认，未实现完整自然语言语义确认协议。
- 自定义图、持久化、人工 interrupt、LangSmith 远端与百炼仍需后续开发及独立授权验证。
