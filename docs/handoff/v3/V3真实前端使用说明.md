## 启动（现有 V3 环境）

在项目根目录 PowerShell 执行。若已有 Streamlit 占用当前终端，先按 Ctrl+C 停止自己启动的服务，然后运行以下命令。

```powershell
$env:PYTHONIOENCODING="utf-8"
$env:AGENT_ENGINE="langchain"
$env:AGENT_PROVIDER="mock"
$env:AGENT_LC_TOOLSET="all"
$env:AGENT_USE_HTTP="0"
$env:AGENT_VECTOR_RAG="0"
$env:AGENT_MAX_STEPS="8"
# 独立演示数据，避免影响原数据库和原 Trace。
$uiRun = Get-Date -Format "yyyyMMdd-HHmmss-ffff"
$env:AGENT_DB_PATH="$PWD\artifacts\runtime\ui-$uiRun\tickets.db"
$env:AGENT_TRACE_DIR="$PWD\artifacts\runtime\ui-$uiRun\traces"
.\.venv-v3\Scripts\python.exe data/seed.py
.\.venv-v3\Scripts\python.exe -m streamlit run web/app.py
```

打开终端显示的 Local URL，通常为 `http://localhost:8501`。界面出现 `LangChain Mock` 时表示框架实际运行、模型决策使用离线 Mock，并非真实大模型实测。新前端没有新增 Python 依赖；安装方法沿用 [B 的 V3 手册](B_V3测试对接手册.md)。原环境 `.venv` 仍可运行 legacy 界面。

想演示变异：停止自己启动的服务，将 `AGENT_ENGINE` 改为 `legacy` 再启动。同一测试场景使用相同 session；不同测试用例点击“清空会话”。这只清除对话记忆，不重置库存和订单。需要完全隔离业务数据时使用新的 `uiRun` 目录重新启动。

真实模型配置沿用既有 `AGENT_PROVIDER=openai`、`AGENT_MODEL`、`AGENT_BASE_URL`、`AGENT_API_KEY`；不要把 Key 写入报告、截图或 Git。更换引擎/工具集/模型后重启服务。没有合法有效 Key 时继续使用 Mock。

## 可以现场操作的演示

1. 输入“查明天上海到杭州的高铁”：显示查询回复和班次卡片；右侧调用应为 `query_tickets`。
2. 输入“订明天上海到杭州的高铁”：调用 `query_tickets → lock_seat → create_order`；订单卡片显示“待支付”。
3. 输入“锁座后多久必须完成支付？”：只调用 `search_policy`，显示 P11 等政策来源，不执行支付。
4. 输入“支付我刚才的订单”：实际模拟订单变为“已支付”；再次输入，工具返回 `duplicate_pay=true`，提示没有重复扣款。
5. 右侧选择调用查看参数，展开“工具原始结果”“工具调用表”“完整 JSON”，下载本轮 Trace。
6. 点击“历史记录回放”：选择原始 JSONL 记录；点击“核心代码导览”查看真正的 Python 函数。
7. 点击“清空会话”：新建 session，卡片和聊天清空，历史文件仍能回放。手机可用左上角侧栏按钮展开/收起控制区。

演示耗时使用当次 Trace 的数值，不保证固定值。Mock 常很快，处理中动画可能一闪而过；没有添加人为等待时间。`stop` 表示执行循环结束，不代表业务一定成功。

## 核心代码如何工作

- `web/app.py`：组织侧栏、对话、结果卡片、轨迹、回放与源码导览。发送按钮只执行一次 `Agent.chat()`。
- `web/theme.css`：品牌、浅色面板、余票/订单/政策卡片、响应式布局和旋转动画。
- `web/presentation.py`：展示适配。legacy 从本轮新追加的 tool 消息读取完整 JSON；LangChain 从本轮 `last_events` 的 `tool_end` 读取完整结果。逐项匹配契约调用顺序后深拷贝到当前浏览器 session。
- 完整结果只是 UI 内存数据，未添加到 `Agent.chat()` 返回字段或 JSONL。公共 Trace 保留原来的 10 个顶层字段、5 个 call 字段和 result_preview 截断机制。
- 渲染车次/政策/订单的 HTML 前转义文本，避免把工具返回文本当成可执行 HTML。业务卡片不从模型回复中推测，不从历史截断字符串补造内容。
- 清空会话不清除业务数据；初始化失败仍允许回放；chat 抛异常时不把上一轮结果显示为本轮成功。
