## 1. 项目介绍

真实大模型决定何时查询，LangChain把工具请求交给Python，再把结果交回模型回答。DeepSeek与百炼是独立真实接入，不是Mock改名。真实的是模型API和工具选择；票、价格、库存来自虚构SQLite，不连接真实铁路/航司/支付。

两个模型均实际完成“提问→模型选query_tickets→Python查库→结果回模型→回答”。DeepSeek本次固定查询正确；百炼把两车次时刻对调，不能介绍成两个模型业务全部通过。新增保护能从原错误离线检出；不能说模型自己纠正，不能声称保护已Live复验。Live只开放查票与政策两工具，其余六个代码禁止。
