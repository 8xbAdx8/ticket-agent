## 4. Mock使用方式

在项目根目录，同一个PowerShell里设置：

```powershell
cd D:\codexproject\ticket-agent
$env:PYTHONIOENCODING="utf-8"
$env:AGENT_PROVIDER="mock"
$env:AGENT_ENGINE="legacy"
$env:AGENT_MODEL="mock-offline"
$env:AGENT_LC_TOOLSET="all"
$env:AGENT_USE_HTTP="0"
$env:AGENT_VECTOR_RAG="0"
$env:LANGSMITH_TRACING="false"
$env:LANGCHAIN_TRACING_V2="false"
$runId=Get-Date -Format "yyyyMMdd-HHmmss-ffff"
$env:AGENT_DB_PATH="$PWD\artifacts\runtime\manual-$runId\tickets.db"
$env:AGENT_TRACE_DIR="$PWD\artifacts\runtime\manual-$runId\traces"
.\.venv-deepseek\Scripts\python.exe data/seed.py
.\.venv-deepseek\Scripts\python.exe cli.py chat
```

LangChain Mock只需将AGENT_ENGINE改为langchain，仍用provider=mock。Web在同一终端改用 `python -m streamlit run web/app.py`，解释器仍使用上述虚拟环境完整路径。不要将多个cli once当作同一个多轮会话。

默认未配置Provider时仍为legacy Mock。显式环境变量会覆盖默认值；从Mock切换Live时应设置下节相关参数，不能留下legacy引擎/all工具集/Mock模型标签。
