## 状态含义

| 状态 | 判断依据 |
|---|---|
| disabled | 开关未启用 |
| not_triggered | 启用但当前没有匹配调用/目标 |
| not_applicable | 工具集或场景不支持；如 M8 普通 chat、不同锁座无相同幂等键竞争 |
| blocked | 命中场景但安全层/调用上限不允许实际注入 |
| error | 注入器失败；旧 failed/prepared 兼容归一 |
| applied | 有真实前后变化及执行/结果证据 |

同一项可能有多个事件，不按开关个数替代实际事件个数。原始事件保存在 fault_report 中，规范化事件用 evidence_ref 指向原记录，保留兼容性。
