# 成员 C V3.3 验收与演示说明

日期：2026-10-25。这个项目由模拟票务 Agent 和测试工作台组成：用户提出出行需求，Agent 调用程序查询模拟数据；测试人员注入已知问题，观察工具执行、回复和独立判定。AI 不是库存或订单的事实来源。

## 开始使用

已有 Python 环境时双击根目录 `启动_离线模式.cmd`。无 Key 即可演示，终端保留，结束按 Ctrl+C。首次安装需要 Python 3.12 和锁定依赖，详见根目录启动说明。默认打开 V3.3；旧 V3.2 界面仍保留为兼容入口。

录制优先使用离线模式。在线脚本使用真实 DeepSeek，会收费，默认只能查模拟票和政策；本轮没有做新的在线验证。视频不能把 Mock、SDK 桩或通用加载动画称为真实模型推理过程。

## 可拍摄的真实功能

| 顺序 | 操作 | 应出现的画面 / 验收依据 |
|---|---|---|
| 1 | 打开出行助手 | 深色首页、模型与模拟业务提示、推荐问题、输入框 |
| 2 | 发送“查明天上海到杭州的高铁二等座” | 回复和三张实际模拟查询卡片；票价/余票/发到时间有工具来源 |
| 3 | 问“锁座后多久必须完成支付？” | 政策工具返回，P11 等实际来源；不误当支付操作 |
| 4 | 离线发送“订明天上海到杭州的高铁” | 先显示 UI 确认，确认后才执行原模拟流程；支付不包含在订票授权中 |
| 5 | 切测试工作台 → 总览 | B 各批次、来源日期和版本；101/101 与 100/100 分开，专项/变异/并发不相加 |
| 6 | 实验室选择 Legacy Mock，勾 hallucinated_train，再查票 | 人为注入 G9999；用户模式不受影响；A 实验不是 B 正式成绩 |
| 7 | 展开 Trace / 变异前后 | 原始结果无 G9999、可见结果有 G9999；平台检出与 Agent 恢复独立，未知不涂绿 |
| 8 | 质量分析 → 额外假车次探测，选 T04 | 明确显示 missed 与原始回复，解释“69/69 仅选定组合” |
| 9 | 勾 M8，运行并发对照 | 对话不适用；正常一单、临时影子库故意多单，实际订单和断言可展开 |
| 10 | 模型对比、集成中心 | 两个 Mock 引擎同用例对照；百炼待集成、LangSmith 外传关闭、显式执行图未启用 |
| 11 | 切浅色 | 卡片、JSON、表格和图表保持可读，切换不新增请求 |

不同日期的模拟库存可能变化，以工具实际结果为准，不要把截图里的固定余票写成产品保证。没有某字段时显示未提供。要展示正常购票，先恢复正常模式并新建普通用户会话，避免沿用测试变异。
