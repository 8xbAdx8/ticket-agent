## 原定义与执行证据

- 原开关 `lab_mutation_date_offset` 发送 `{"date_offset": 1}`。注册表只接受整数 `1`，语义为日期向后偏移一天。原场景预设「M1 日期偏移」填入「查明天上海到杭州的高铁二等座」，选预设不会启用开关。
- 「执行测试」沿用 `web.laboratory.render_experiment` → `web.conversation.execute` → `Conversation.send` → 原 Agent。Legacy 通过 `target.providers._parse_date` 在日期解析阶段注入，LangChain 路径通过 `target.fault_injection.FaultRun.arguments` 准备参数。
- 平台独立判定依据 `executed_query_date_matches_user`，比较用户要求日期与实际执行的 `query_tickets.date`。注入应用状态、平台检出、Agent 识别、Agent 恢复分别显示。原审计保存 Trace ID、变异事件 ID、调用 ID、前后值与断言。
- 浏览器最终实测 M1 会话 `web-337e7c4db22f`，Trace `d3c29ac688494c9fbb55816876f417d7`。日期 `2026-11-13` → `2026-11-14`，实际工具调用使用变异后的日期，原独立断言失败且 `platform_defect_detected=true`。刷新后按会话 ID 回放同一 Trace，审计文件 SHA-256 与执行后相同。
