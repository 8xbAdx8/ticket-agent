设计方案：沿用现有主题变量，蓝色强调、白色浅主题/海军蓝深主题、灰蓝辅助文字、细边框。参考token：铁路蓝#1556D0、浅蓝#E6EFFF、纸白#FFFFFF、深蓝#102338、辅助灰蓝#91A5BD、边框#D6E0ED；实现始终引用项目ta主题变量，不覆盖全局色板。字体沿用项目字体，时间32px数字等宽，站名16px、辅助13px，正文原16px与1.7行高保留。

方案审视：去掉原数据质量列、原始ID、版本、状态码和重复中间卡。视觉重点只放时刻和行程，保留一条静态/模拟边界说明。没有引入新框架、网络字体、动画和重复免责声明。20条分页保留，不预取109份经停。
